# PlateSolve 粗匹配优化策略设计

## 一、星点选择策略

### 1.1 图像星点选择顺序
按亮度顺序选择，优先饱和星点：
1. 先取全部饱和星点（按流量排序）
2. 再取未饱和的最亮星点（按流量排序）
3. 合并后按亮度从高到低排序

### 1.2 Gaia星点选择顺序
按亮度顺序选择（mag从小到大）：
1. 取最亮的Gaia星点
2. 按星等排序，优先亮星

### 1.3 初始放行数量
| 条件 | 图像星点放行 | Gaia星点放行 |
|------|-------------|-------------|
| 饱和星≥10颗 | 全部饱和星 | min(饱和星×1.5, n_cat) |
| 饱和星<10颗 | 100颗（饱和星+最亮星） | 150颗 |

## 二、动态重试机制

### 2.1 重试触发条件
当RANSAC过滤后匹配数≤10对时，触发动态重试。

### 2.2 重试策略
图像星点放行数量按2幂次增加：100 → 200 → 400 → 800（最大800）

Gaia星点放行数量按1.5x图像星点数量增加：
| 图像放行 | Gaia放行（1.5x） | 实际Gaia（不超过3000） |
|---------|-----------------|----------------------|
| 100 | 150 | min(150, n_cat) |
| 200 | 300 | min(300, n_cat) |
| 400 | 600 | min(600, n_cat) |
| 800 | 1200 | min(1200, n_cat) |
| 800 | 1200 | min(1200, n_cat) |

### 2.3 重试终止条件
- RANSAC匹配数>10对：成功，停止重试
- 达到最大重试次数（800星点）：若仍≤10对，报告失败
- Gaia星点耗尽（n_cat不足）：使用全部可用星点

### 2.4 饱和星≥10颗的特殊处理
饱和星≥10颗时，只尝试一次（使用全部饱和星），不触发动态重试。

## 三、三角形匹配剪枝策略

### 3.1 匹配数阈值分级处理
| RANSAC匹配数 | 处理策略 |
|-------------|---------|
| ≤10对 | 报告失败（重试后仍≤10） |
| 11-20对 | 跳过三角形剪枝，直接使用RANSAC结果 |
| 21-100对 | 使用三角形剪枝优化 |
| >100对 | 空间筛选 + 三角形剪枝 |

### 3.2 空间筛选策略（匹配数>100对）
当匹配数>100对时，为降低运算量，按空间均匀分布筛选星点：
1. 将图像划分为网格（如8×8）
2. 每个网格内取匹配质量最好的若干星点
3. 篮选后约100-200颗星点进入三角匹配流程
4. 保证星点在图像上均匀分布，避免集中某一区域

### 3.3 三角形剪枝流程
1. 构建三角形特征（边长比、角度）
2. KDTree匹配相似三角形
3. 验证三角形一致性
4. 过滤误匹配

## 四、成功判定标准

### 4.1 最终成功条件
- matched_count > 10
- rms_px < 5.0

### 4.2 失败报告
当重试后仍无法达到>10对匹配时，返回：
- matched_count（实际匹配数）
- rms_px（RMS值）
- 重试次数
- 最终使用的星点放行数量

## 五、实现架构

### 5.1 C++端职责
- 星点检测（star_detector）
- 星点选择与排序
- 动态重试逻辑
- RANSAC过滤
- 三角形匹配剪枝
- 空间筛选
- 返回最终结果

### 5.2 Python端职责
- 图像读取
- FITS头解析（获取初始坐标、焦距等）
- 调用C++接口（solve_with_image）
- 结果展示与记录

### 5.3 API接口
```cpp
int psolve_solve_with_image(
    PSolveHandle handle,
    const uint16_t *image, int width, int height,
    const PSolveImageData *img_data,
    const PSolveConfig *config,
    PSolveResult *result
);
```

Python端只需传入图像和基本参数，C++端完成全部处理。

## 六、流程图

```
图像输入
    ↓
星点检测（C++端）
    ↓
星点分类（饱和星/普通星）
    ↓
按亮度排序
    ↓
初始放行（饱和星≥10: 全部饱和星; <10: 100颗）
    ↓
Gaia星点查询与排序
    ↓
初始Gaia放行（1.5x图像放行）
    ↓
RANSAC匹配
    ↓
匹配数判断
    ├─ >10对 → 成功，进入剪枝判断
    │   ├─ 11-20对 → 跳过剪枝
    │   ├─ 21-100对 → 三角形剪枝
    │   └─ >100对 → 空间筛选 + 三角形剪枝
    │   ↓
    │   返回结果
    │
    └─ ≤10对 → 触发重试
        ↓
        图像放行×2（100→200→400→800）
        ↓
        Gaia放行×1.5（不超过3000）
        ↓
        RANSAC匹配
        ↓
        循环直到>10对或达到最大重试
        ↓
        返回结果（成功或失败）
```
