# 初始WCS匹配算法重设计 Spec

## Why
当前三角匹配算法在实际数据上完全失败（ba/ca匹配半径0.002对像素坐标不适用），KDTree回退方案RMS=21.7px远超2px目标，翻转模式检测错误。根本原因：三角匹配的匹配半径需要精确的坐标归一化，而我们的坐标系统与siril的归一化坐标不同；KDTree回退使用全部星点（14000×21000）导致5px半径下产生~1400个随机假匹配。

**核心物理洞察**：饱和星和排名靠前的亮星中，超过一半一定与Gaia最亮星一一对应——因为最亮的恒星在天空中是客观存在的，无论探测器如何，只要在FOV内且未饱和到不可检测，就必然被观测到。利用这一物理事实，只需对少量亮星（≤50颗）进行结构匹配，随机匹配概率趋近于零，从而建立可靠的点对点对应，过滤异常后求解精确初始WCS。

## What Changes
- **替换** 三角匹配算法为亮星结构匹配算法（基于多边形不变性）
- **替换** 4种翻转模式独立测试为仿射行列式翻转检测
- **新增** 四边形不变性结构特征索引（5维排序距离比值+亮度排序约束）
- **新增** 特征空间KDTree匹配+投票机制
- **修复** 迭代重投影收敛问题（匹配半径5px→2px，重投影半径收紧）
- **修复** scale_arcsec_px报告错误（仿射线性模→输入像素尺度）
- **BREAKING** match_with_flip()和select_best_flip()替换为bright_star_structural_match()

## Impact
- Affected specs: initial-wcs-rewrite
- Affected code: lib/plate_solve/python/initial_wcs.py（匹配算法核心重写）

## ADDED Requirements

### Requirement: 亮星选择与对应保证
系统 SHALL 从图像侧选择饱和星+最亮N颗正常星（总计≤50颗），从Gaia侧选择最亮M颗（M=2×N_img），确保>50%的图像亮星在Gaia亮星中有对应。

选择策略：
- 饱和星≥10颗：图像侧取最亮50颗饱和星，Gaia侧取100颗最亮星
- 饱和星<10颗：图像侧取饱和星+最亮正常星共30颗，Gaia侧取60颗最亮星

#### Scenario: 饱和星充足
- **WHEN** 检测到163颗饱和星
- **THEN** 图像侧使用50颗最亮饱和星，Gaia侧使用100颗最亮星

#### Scenario: 饱和星不足
- **WHEN** 检测到5颗饱和星
- **THEN** 图像侧使用5颗饱和星+25颗最亮正常星=30颗，Gaia侧使用60颗最亮星

### Requirement: 四边形不变性结构特征索引
系统 SHALL 对亮星集合构建四边形结构特征描述子，用于翻转不变的匹配：

1. 对每组4颗星，计算6条边长并排序：d[0]≤d[1]≤d[2]≤d[3]≤d[4]≤d[5]
2. 计算5个不变比值：r[m] = d[m+1]/d[0]，m=0..4
3. 这些比值对旋转、平移、缩放、翻转完全不变（仅依赖距离，距离与坐标变换无关）
4. 附加亮度排序约束：4颗星按亮度排序的置换模式必须兼容

特征匹配半径：0.01（每个比值1%容差），相比三角匹配的0.002更宽松但维度更高（5维vs2维），综合区分力更强。

#### Scenario: 特征不变性验证
- **WHEN** 对同一组4颗星施加任意旋转、平移、缩放或翻转
- **THEN** 5个排序距离比值完全不变

#### Scenario: 与三角匹配对比
- **WHEN** 三角匹配用2维(ba,ca)空间radius=0.002
- **THEN** 四边形5维特征空间radius=0.01提供更强的区分力（5个独立约束vs2个）

### Requirement: 结构特征匹配与投票
系统 SHALL 使用KDTree在5维特征空间中匹配图像和星表的四边形特征，通过投票建立星点对应关系：

1. 构建星表四边形特征KDTree（5维）
2. 对每个图像四边形特征，查找最近邻星表特征（半径0.01）
3. 亮度排序兼容性检查：图像4颗星的亮度排名与星表4颗星的星等排名必须一致（允许±2排名偏移）
4. 每个匹配的四边形对为4个星点对应投票
5. 累积投票后，对每个图像星选择票数最高的星表星
6. 应用互为最佳约束去重
7. 选择票数≥2的对应对

#### Scenario: 正确对应发现
- **WHEN** 30颗图像亮星中有20颗与Gaia亮星对应
- **THEN** 投票后20颗正确对应获得≥5票，错误对应票数≤1

#### Scenario: 亮度约束过滤
- **WHEN** 一个四边形匹配的亮度排序不兼容
- **THEN** 该匹配被拒绝，不参与投票

### Requirement: 异常过滤与仿射求解
系统 SHALL 从投票得到的对应对中，通过迭代过滤求解精确仿射变换：

1. 从所有对应对计算仿射变换（6参数最小二乘）
2. 应用变换计算每对残差
3. 3-sigma clip去除残差过大的异常对
4. 重新计算仿射变换
5. 迭代至无异常被移除或达到10次迭代

#### Scenario: 异常过滤
- **WHEN** 30个对应对中有5个错误匹配
- **THEN** sigma-clip后5个错误匹配被移除，剩余25对用于精确仿射求解

### Requirement: 仿射行列式翻转检测
系统 SHALL 从仿射变换的线性部分确定翻转模式，无需4模式独立测试：

使用未翻转的星表坐标计算仿射变换，根据系数确定翻转：
- det(a1×b2 - a2×b1) > 0 且 a1 > 0: 正常模式 (flip_mode=0)
- det > 0 且 a1 < 0: XY翻转 (flip_mode=3)
- det < 0 且 a1 < 0: X翻转 (flip_mode=1)
- det < 0 且 a1 > 0: Y翻转 (flip_mode=2)

确定翻转后，应用翻转到星表坐标，重新计算仿射变换。

#### Scenario: 正常图像
- **WHEN** 图像无翻转
- **THEN** 仿射a1≈1.0>0, det≈1.0>0, flip_mode=0

#### Scenario: Y翻转图像
- **WHEN** 图像存在Y翻转
- **THEN** 仿射b2≈-1.0, det<0, a1>0, flip_mode=2

### Requirement: 全星点验证匹配
系统 SHALL 在亮星匹配获得精确仿射后，用全部星点进行验证匹配：

1. 应用仿射变换+翻转预测所有星点位置
2. KDTree匹配（半径2px，不是5px）
3. sigma-clip过滤异常对
4. 重新计算仿射变换
5. 迭代2-3轮至稳定

#### Scenario: 验证匹配扩展
- **WHEN** 亮星匹配给出25对
- **THEN** 全星点验证后匹配数增长到>500对，RMS<2px

### Requirement: 迭代重投影收敛
系统 SHALL 在匹配完成后进行迭代重投影收敛：

- 收敛条件: offset < 0.01 arcsec
- 最大迭代: 5次
- 重投影匹配半径: [30, 10, 5, 2]（逐步收紧，不是[100, 50, 30, 10, 5]）
- 最终匹配半径: 2px（不是5px）

#### Scenario: 收敛
- **WHEN** 初始中心偏差<1度
- **THEN** 1-2次迭代即收敛，offset < 0.01 arcsec

### Requirement: 正确的比例尺报告
系统 SHALL 在结果中正确报告scale_arcsec_px：
- 使用输入的像素尺度（从焦距和像元尺寸计算：206.265 × pixel_um / focal_mm）
- 不使用仿射变换的线性部分模（那是像素到像素的尺度比，≈1.0）

#### Scenario: 比例尺报告
- **WHEN** 焦距200mm，像元6um
- **THEN** scale_arcsec_px = 6.188 arcsec/px

## MODIFIED Requirements

### Requirement: InitialWCS.solve()流程
solve()方法 SHALL 执行以下6步流程（替代原来的7步）：

1. **计算像素尺度和FOV**（不变）
2. **Gaia锥形查询 + 极限星等二分法**（不变）
3. **Gnomonic投影**（不变）
4. **亮星结构匹配**（新算法，替代原Step4+5）：
   - 4a: 亮星选择（饱和+最亮≤50颗 vs Gaia最亮2×N颗）
   - 4b: 四边形特征计算（5维排序距离比值+亮度排序）
   - 4c: 特征空间KDTree匹配+投票→建立对应
   - 4d: 异常过滤（sigma-clip）→控制点对
   - 4e: 仿射变换求解
   - 4f: 仿射行列式翻转检测
5. **全星点验证匹配**（修改：半径2px，不是递减50→30→10→2）
6. **迭代重投影收敛**（修改：收紧半径，最终2px）

## REMOVED Requirements

### Requirement: 4种翻转模式独立三角匹配
**Reason**: 三角匹配在实际数据上完全失败（ba/ca空间匹配半径0.002对像素坐标不适用）；4模式独立测试不必要，仿射行列式可确定翻转
**Migration**: 用亮星四边形结构匹配+仿射行列式翻转检测替代

### Requirement: 三角匹配算法（set_triangle/build_triangles/triangle_match）
**Reason**: ba/ca空间匹配半径校准于siril归一化坐标，在像素坐标下失效；2维特征空间区分力不足
**Migration**: 用四边形5维排序距离比值特征替代
