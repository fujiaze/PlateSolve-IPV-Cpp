# 向量匹配算法 V4.0 设计文档

## 1. 动机

### 1.1 V3 系列的根本局限

V3.3/V3.5 在 562 帧测试中达到 83.1% 成功率，但存在以下结构性缺陷：

**分阶段架构导致信息闭塞**：Phase A（盲目抽样）→ Phase B（后处理过滤）→ Phase C（拟合），三个阶段之间信息不流通。Phase A 中已积累的正确匹配对不会反过来改善后续抽样的效率——每轮随机抽样独立且同等盲目，K=10000 次中绝大多数是无效抽样。

**相似度指标维度单一**：V3 的 `n_in_range_s`（变换后模长比在 [0.9, 1.1] 范围内的计数）只用到模长比信息，丢弃了向量组的空间结构和局部几何关系。正确约 200 vs 错误约 1~3，动态范围约 100 倍。在畸变大、星点分布不均匀的场景下，正确和错误的指标分布存在重叠区，导致 θ 直方图的 SNR 不够清晰。

**无收敛机制**：V3 没有"模型正在变好"的概念。固定 K=10000 次抽样后强制停止，即使 2000 次时已经找到足够正确对，剩余 8000 次仍是浪费。

### 1.2 V4 的核心愿景

将 platesolve 实现为一个**渐进收敛的闭环系统**：

```
模型越准 → 抽样越准 → 模型更准 → 抽样更准 → ...
```

这是一个正反馈循环，效率指数级提升。从最具辨识度的亮星地标起步，快速找到第一个可靠匹配，然后模型反哺抽样、池逐渐扩增，直到参数稳定收敛。

### 1.3 关键洞察

1. **亮星即地标**：饱和星和亮星是最可靠的信标，初始阶段只用它们可以 10 倍提升正确抽样的概率密度
2. **结构即指纹**：正确匹配的向量组不仅在整体上相似，更关键的是**局部亮星之间的构型关系**几乎不变——这是畸变无法摧毁的指纹
3. **模型即方向**：一旦有一个粗糙模型，抽样就不再盲目——可以通过模型投影预测匹配位置
4. **收敛即停止**：当模型参数不再显著变化时，再抽样也无益，应主动停止

## 2. 算法原理

### 2.1 整体架构：两阶段收敛

V4 将 platesolve 实现为一个**两阶段闭环收敛系统**。

**第一阶段**：用小而精的初始池通过指纹加权抽样 + SCM 验证，快速积累高置信度控制点。池内双向匹配去杂后 RMS < 0.5px 时拟合 CD + SIP，然后触发第二阶段。

**第二阶段**：用第一阶段建立的 CD + SIP 模型，对图像侧前 2000 亮星和星表侧前 5000 亮星做邻近双向匹配 + RANSAC，快速扩增控制点到全覆盖。

```

│                      V4.0 两阶段收敛架构                            │
│                                                                     │
│  第一阶段：初始池探索（控制点从零积累到 RMS < 0.5px, 然后拟合 CD+SIP） │
│  ┌──────────────────────────────────────────────────────────┐      │
│  │ 初始池 (固定大小, 指纹加权, 不重复抽样)                    │      │

│  │                                                           │      │

### 2.2 核心理念：控制点驱动的收敛

整个求解过程的唯一可信信息来源是**控制点对**——每一对都是经过 SCM 或双向匹配验证的 (图像星, 星表星) 匹配。

流程概括（以下三个进程在同一个循环中同步交织进行，不是先后顺序）：

**进程A — 探索抽样**：
  初始池中指纹加权抽取未评估对 → 单对解算 CD → SCM 评分 → 通过则进入控制点池
  始终运行，保持从初始池中发现新控制点

**进程B — 收敛抽样**：
  一旦有可用模型，用模型约束引导后续抽样 → |θ-θ_model|<阈值 → tx,ty约束
  跳过明显不合法的配对，不浪费 SCM 计算

**进程C — RANSAC 实时清洗**：
  控制点池 ≥ 5 对时自动启动 → 反复子抽样→拟合→全量验证→标记离群
  新控制点加入时实时触发新一轮清洗，始终离群的对被永久剔除
  清洗后的干净内点集立即用于更新模型，反哺进程B的约束

三者交织推进：
  进程A发现新对 → 进程C清洗后模型更新 → 进程B约束收紧 → 进程A命中率上升 → 正向循环

第一阶段结束条件：双向不匹配点全部清除 且 RMS < 0.5px → LSQ 拟合 CD + SIP
第二阶段：携带 CD + SIP 模型 → 扩增池邻近双向匹配 → 全部控制点重拟合

### 2.3 第一阶段：初始池探索（三进程同步）

#### 2.3.0 循环结构

第一阶段是一个统一的循环，探索抽样、收敛抽样和 RANSAC 清洗交织在同一轮迭代中：

```
while RMS ≥ 0.5px 或有双向不匹配点:
  1. 进程A: 从初始池中指纹加权抽一对未评估的 (u, w)
     若无模型 → 直接进入SCM评估
     若有模型 → 先过约束关(进程B), 不合法则跳过本次迭代
  2. 进程A: s约束 → θ约束 → tx,ty约束 → SCM评分 → 通过则加入控制点池
  3. 进程C: 控制点池 ≥ 5对 → 立即触发新一轮RANSAC子抽样清洗
     清洗后的内点集 → Umeyama → 更新当前模型
  4. 进程C: 双向不匹配检查(用更新后的模型) → 剔除不一致对
  5. 进程B: 模型更新后 → 收紧后续抽样的约束阈值
  6. 检查收敛: RMS < 0.5px 且 无不匹配点 → 结束第一阶段
```

#### 2.3.1 构成

```
图像侧 (U侧):
  搜索框: 图像中心到该星的距离 ≤ min(图像宽度, 高度) × 0.48
  选星规则: 饱和星优先, 若不足则取最亮的非饱和星, 总数 ~30-50
  
星表侧 (W侧):
  按 Gaia G 星等排序, 取最亮的 ~100 颗
  来源: 以图像中心为圆心, FOV × 0.65 为半径的锥形查询结果
```

#### 2.3.2 指纹加权

每颗初始池中的星计算两个局部密度特征：

```
全局密度: 以该星为圆心, 半径 = 全部检测星平均最近邻距离 × 3
          统计落在圆内的全部检测星数量 → d_global

亮星密度: 同样的圆, 但只统计池内亮星 → d_bright

权重 = d_bright / max(d_global, 1)

含义:
  比值接近1 → 该星的局部邻居几乎全是亮星 → 构型独特、不易与其他星混淆
  比值远小于1 → 该星周围有很多暗星干扰 → 容易误匹配
```

抽样时按权重概率选取，权重大于中位数的星被优先抽中。

#### 2.3.3 不重复抽样

初始池的 (图像星, 星表星) 配对空间是固定的（~50 × 100 = 5000 对）。每次抽样后标记已访问，直到池中所有对都评估过。

#### 2.3.4 快速约束跳过

在有模型的情况下，每对候选在进入 SCM 评估前先过约束关：

```
1. s 约束: s = |U[u]| / |W[w]|, 必须在 [0.85, 1.15] 内
2. 方向约束: |atan2(U[u]) - atan2(W[w])| 与模型 θ 的差 < 阈值(初始15°, 收紧到2°)
3. tx,ty 约束: |tx| < 0.6 × FOV半宽, |ty| < 0.6 × FOV半高
4. 不合法 → 直接跳过, 不浪费 SCM 计算
```

### 2.4 控制点池（贯穿两阶段）

#### 2.4.1 构成

```
初始: 空
增长: 每次验证通过的控制点对 → 加入池
容量: 无上限, 第一阶段自然增长到 ~20-50 对, 第二阶段扩增到 ~100-500 对

每对记录:
  · 图像星像素坐标 (x, y)
  · 星表星天球坐标 (ra, dec)
  · 离群计数器 (初始0, RANSAC中每被判为外点一次则+1)
```

#### 2.4.2 RANSAC 实时清洗

与探索抽样和收敛抽样同步运行。每当有新控制点加入池，或池大小达到 5 的倍数时，立即触发新一轮 RANSAC 子抽样清洗：

```
每次RANSAC清洗轮:
  1. 从控制点池中随机抽 3 对
  2. 用这 3 对做 Umeyama 相似变换 → (s, θ, tx, ty)
  3. 用 (s, θ, tx, ty) 对池中所有控制点做投影验证
  4. 残差 < 阈值的标记为内点
  5. 对每对: 如果是外点, 离群计数器 +1
  6. 内点数超过当前最佳 → 更新最佳模型和内点集

重复至收敛或达上限

结束条件: 连续N轮最佳内点数无变化 → 停止
```

离群计数器的作用: 多轮RANSAC后，始终离群的控制点被**永久剔除**。

#### 2.4.3 第一阶段结束条件

```
双向不匹配检查:
  对池中每对控制点:
    用当前 CD 模型将图像星反向投影到天球 → 在 Gaia 表中找最近邻
    用当前 CD 模型将星表星正向投影到图像 → 在检测星中找最近邻
    若正向和反向的最远邻不是同一对 → 标记为不匹配 → 剔除

重复 RANSAC + 双向检查，直到:
  (a) 无不匹配点被检出
  (b) RMS < 0.5px

满足条件后:
  用当前干净控制点做 LSQ 像素→天空拟合 → CD 矩阵
  畸变残差 → SIP 拟合
  输出 CD + SIP → 进入第二阶段
```

### 2.5 第二阶段：扩增池

#### 2.5.1 触发条件

第一阶段 RMS < 0.5px、无不匹配点、已完成 CD + SIP 拟合 → 构建扩增池。

#### 2.5.2 构成

```
图像侧: 全部检测星按 flux 降序取前 2000 颗
星表侧: 全部 Gaia 星按 Gmag 升序取前 5000 颗

不需要指纹加权（模型已足够精确，直接用邻近匹配）
```

#### 2.5.3 邻近双向匹配

```
对扩增池中每颗图像星:
  1. 用 CD 模型将该星投影到天球坐标 (ra, dec)
  2. 在星表侧前 5000 颗中找最近邻
  3. 若距离 < 阈值: 标记为一对候选

对每对候选:
  4. 反向验证: 将星表星用 CD 模型投影到图像坐标
  5. 在图像侧中找最近邻
  6. 若正向和反向的最远邻一致 → 确认为新控制点

RANSAC 过滤:
  从新确认的控制点中随机抽子集 → 拟合 → 全量验证 → 剔除离群
```

#### 2.5.4 最终 CD + SIP 拟合

```
所有控制点（第一阶段 + 第二阶段）:
  CRVAL = 全部控制点 Gaia 坐标的中位数
  像素→天空 LSQ 拟合 → CD 矩阵
  残差 → 畸变径向缩放校正 → SIP 拟合
 ```

### 2.6 结构一致性度量（SCM）

SCM 的定义和计算方式保持不变（详见 2.2.1~2.2.4 的原始描述）。核心参数：

```
SCM = Coverage^0.3 × Configuration^0.7
阈值: 0.40 (原型验证确认的正确/错误分布分界值)
```

SCM 始终在池1的亮星子集上计算（~50颗U + ~100颗W），不受池2大小影响。

### 2.6 CD 矩阵拟合

控制点积累到足够数量后，CD 矩阵通过**最小二乘法**直接从控制点对拟合：

```
输入: n 对控制点 {(xᵢ, yᵢ), (raᵢ, decᵢ)}, CRPIX = (w/2, h/2)
       CRVAL = (ra中位数, dec中位数)

待求解: 4 个 CD 元素 [cd00, cd01, cd10, cd11]

方程组 (每对出两个方程):
  (raᵢ - crval_ra) × cos(crval_dec) = cd00 × (xᵢ - crpix₁) + cd01 × (yᵢ - crpix₂)
  (decᵢ - crval_dec)                = cd10 × (xᵢ - crpix₁) + cd11 × (yᵢ - crpix₂)

最小二乘解 → CD 矩阵
```

这一方法**数学上等价于CD矩阵的定义**，没有解析公式的翻转/符号/象限问题。

### 2.7 4种翻转模式

与 V3.5 一致，四种翻转模式独立并行运行：

```
模式0: Wf = ( Wx,  Wy)    原始
模式1: Wf = (-Wx,  Wy)    X轴翻转
模式2: Wf = ( Wx, -Wy)    Y轴翻转
模式3: Wf = (-Wx, -Wy)    对角线翻转
```

每种模式独立运行完整的两阶段流程。最终选 RMS 最低的模式。

### 2.8 收敛判定

```
第一阶段循环中:
  条件A (初始池耗尽): 初始池中所有未评估对都已抽完
  条件B (控制点饱和): RANSAC连续100轮最佳内点数无变化 且双向无不匹配点 且 RMS < 0.5px
  条件C (预算耗尽): 总抽样次数 ≥ 上限

第二阶段:
  双向邻近匹配完成 + RANSAC收敛 → 最终 CD+SIP 拟合
```

## 6. 关键技术细节

### 6.1 3-NN 构型签名的实现要点

```
signature_KNN3(points, N):
  对每颗星 i (0..N-1):
    计算到所有其他星 j 的距离平方 (提前计算 dx²+dy², 可SIMD)
    用部分排序或小顶堆保留最小的3个距离
    记录3个最近邻的idx和距离
    计算:
      f1 = d1 / median_d1_all   (除以全体星的中位最近邻距离)
      f2 = d2 / d1              
      f3 = angle(p, q1, q2) / π 
         = acos(dot(p→q1, p→q2) / (d1·d2)) / π

  Total: O(N²) 距离计算, N≤250时可行
  SIMD优化: 4个星同时与同一个参考星计算距离 (4-way vectorized)
```

### 6.2 Coverage 网格化实现

```
grid_histogram_intersection(points_U, N, points_Wt, M, center_ratio, center_res, edge_res):
  对于中心区域网格 (center_res × center_res):
    boundary = [-center_ratio·halfW, center_ratio·halfW] × [-center_ratio·halfH, center_ratio·halfH]
    每条边有 center_res 个格子
  
  对于边缘区域: 分上下左右四段, 各用 edge_res 个格子
  
  遍历U: 确定每星落在哪个格子 → H_U[idx]++
  遍历Wt: H_Wt[idx]++
  
  sum_min = Σ min(H_U[i], H_Wt[i])
  sum_max = Σ max(H_U[i], H_Wt[i])
  
  return sum_min / max(sum_max, 1.0)
```

### 6.3 RANSAC 子抽样 + 离群跟踪

```
池2_ransac_filter(控制点池):
  if 控制点池.size < 5: return
  
  离群计数器 map<对ID, int> 全部初始化为0
  最佳内点集 = []
  
  for 轮次 in 1..300:
    从控制点池中随机抽 3 对
    Umeyama_SVD(这3对) → (s, θ, tx, ty)
    用(s,θ,tx,ty)对池中所有控制点做投影验证
    计算每对的投影残差
    内点 = 残差 < 阈值 的对
    for 每对 in 控制点池:
      if 该对不是本次内点: 离群计数器[该对] += 1
    
    if len(内点) > len(最佳内点集):
      最佳内点集 = 内点
  
  剔除: 离群计数器 > 总轮次×0.5 的对永久删除
  返回: 最佳内点集
```

### 6.4 不重复抽样策略

探索池的配对空间是固定的（~50颗U × ~100颗W = ~5000对）。使用一个位图标记每对是否已评估过：

```
每次抽样:
  从池1中按指纹权重加权随机选取 (u_idx, w_idx)
  检查位图[ u_idx × |W| + w_idx ] 是否已标记
  若已标记 → 重新选取
  若未标记 → 标记为已访问 → 进入约束检查

结束条件 (收敛条件A):
  池1中所有未评估对都已访问完 → 探索池耗尽
```

这与 V3 一致，区别在于采样顺序不再是均匀随机，而是指纹加权。

### 10.2 开发过程中发现的问题及解决方案

#### 问题1: 翻转模式下 CD 矩阵符号错误
**现象**: CD 矩阵计算时未考虑翻转模式，导致投影后 Gaia 星位置完全错位（残差 >2000px），角度偏差 ~77°。

**根因**: `_build_wcs_json` 直接用 `s, θ` 计算 `CD = R(θ)⁻¹ × s₀/(s×3600)`，但 θ 是在翻转后的 Wf 空间计算的——`U = s·R(θ)·Wf + t`，其中 `Wf = Flip(W)`。未对 Flip 矩阵求逆再复合 `R(θ)`。

**解决**: ≥15 对时用匹配对直接做像素→天空的线性最小二乘拟合 `dRA_cosδ/dDec = CD · [dx, dy]`，自动适应任何翻转模式。不足 15 对时用翻转修正的 CD 公式（对每个 mode 单独计算复合矩阵 `M = R(θ)·Flip`，然后 `CD = M⁻¹ × s₀/(s×3600)`，且 Y 行取负以处理天文 Y↑ 与 FITS 像素 Y↓ 的方向差异）。

#### 问题2: 引导抽样导致的匹配对重复膨胀
**现象**: `confirmed` 列表从 k≈60 开始爆发式增长到 2700+ 对，但实际只有 ~40 对是独一无二的匹配。其余全是引导抽样反复命中同一对。

**根因**: 引导抽样无去重机制。p_guided=0.95 后，几乎每次引导都从同一个小候选池中抽样，连续命中相同的 (u_idx, w_idx)。

**解决**: 新增 `confirmed_set` (bit-packed uint64 key) 去重。`if pair_key not in confirmed_set: confirmed_set.add(pair_key); confirmed.append(...)`。

#### 问题3: 池扩增后引导抽样完全失败
**现象**: L0→L1 扩增后，引导抽样的 2500+ 次尝试中只有 1 次命中，其余全部浪费。

**根因**: (1) L0→L1 扩增条件太宽松（≥3 对就扩增），3 对拟合的模型不够精确；(2) p_guided 在模型差时过高（3 对就给 0.86），导致大量迭代浪费在坏模型的引导上；(3) τ_guided 自适应公式在稀疏度 221" 时给出 169"，小于模型误差。

**解决**: (1) L0→L1 的扩增阈值提升到 ≥5 对；(2) p_guided 在 <5 对时压制到 `min(0.40, 0.12×n)`，确保模型可靠后才开始高强度引导；(3) `no_expand=True` 模式是当前最优策略——纯 L0 池足以找到足够多正确对。

#### 问题4: 少数匹配对中存在旋转和尺度离群值
**现象**: 个别确认对虽然通过了 SCM 阈值，但其隐含的 s 或 θ 与共识值偏差较大（如某对的 θ 偏离中位数 >5°）。

**根因**: SCM 的 Coverage 和 Configuration 都是局部/统计度量，个别错误匹配可能在局部维度碰巧得分不低。

**解决**: 新增双因子 MAD 离群剔除（`_filter_outliers`）：
- **因子1: 单点 (s, θ) 一致性**：计算每个确认对各自的 `s_i = |U[u_i]|/|W[w_i]|` 和 `θ_i`，对 s 和 θ 分别做 MAD 统计，剔除偏离 >3σ 的对。此因子主要过滤旋转和尺度错误的抽样。
- **因子2: 向量残差一致性**：用当前 Umeyama 模型计算每对的投影残差 `(dx, dy) = U - s·R·W - t`，对 dx 和 dy 分别做 MAD 统计，剔除偏离 >3σ 的对。此因子主要过滤平移错误的抽样。
- 两因子同时通过才保留。
- 触发策略：≥8 对后，在 2 的幂次时刻自动运行（k=8, 16, 32, ...），既不过滤太频繁也不漏过滤。

M20_T2 测试：mode=1 从 46 对中过滤掉 4 对假匹配（~9%），剩余 42 对的角度偏差中位数从 -63° 降至 -1.12°。

 #### 问题5: 后处理 NN 扩张 + 池扩增过早 → 残差迸发到 107px
 **现象**: 循环结束后用 KDTree NN 无 SCM 验证硬捞匹配对做 Umeyama（与 V3.5 已移除的 Phase C 全局NN扩充同款反模式），导致 107px 残差。同时池从 L0→L1 在 1 对时就扩增，搜索空间从 5000 膨胀到 50000，匹配密度从 0.3% 骤降到 0.06%，1 对模型毫无引导能力，后续匹配完全停滞。

 **根因**:
 1. "后处理"用当前模型投影 Wf_all → NN U_all → 直接列为匹配对，无 SCM 验证。NN 在不同模型下匹配到不同位置，大量假对污染 Umeyama。
 2. L0→L1 在 ≥1 对时触发，单对模型的 τ_guided=200" 在 500×100 搜索空间下仍然不够，引导抽样 3000+ 次尝试全部失败。
 3. p_guided 为 0.62 (1对)，86% 引导在坏模型上全是浪费。

 **解决**:
  - **完全移除后处理 NN 扩张代码**
  - **L0→L1 扩增阈值提升到 ≥8 对**：6-8 对 Umeyama 模型的引导在 L1 中开始有效（结果: k=72 扩增, k=372 收敛, 8 对确认）
  - **τ_guided 从池稀疏度解耦**：`τ_guided = max(5, 300/(1+0.5×n))` — 初始 300", 1对 200", 3对 120", 5对 85", 8对 60"
  - **新增全仿射拟合**：≥5 对时 `dst = A·src + t` 最小二乘拟合，从仿射矩阵提取等效 s/θ/tx/ty
  - **还原 p_guided 为 spec 公式**：`min(0.95, 0.5 + 0.12×n)`，不压制

 **修正后结果**:
 ```
 mode=1: L0(k=0-70)→8对→离群剔除6对→L0→L1(k=72)→k=372收敛

## 11. 设计原则 (2026-06-10 修订：两阶段收敛)

1. **两阶段解耦**：第一阶段用小而精的初始池（饱和星+亮星，指纹加权）积累高置信度控制点；第二阶段用 CD+SIP 模型在扩增池中快速匹配。两个阶段职责明确，不相互污染。
2. **三进程同步**：探索抽样、收敛抽样和 RANSAC 清洗在同一循环中同步交织运行。进程A发现新控制点 → 进程C清洗后更新模型 → 进程B收紧约束 → 进程A命中率上升，形成实时正向反馈。
3. **控制点驱动**：求解全过程唯一可信信息源是 SCM 或双向匹配验证通过的控制点对。CD 矩阵、畸变校正、SIP 拟合全部从控制点对直接计算。
4. **RANSAC 实时清洗**：不是独立的"后处理阶段"，而是与控制点积累同步进行的实时机制。每有新控制点加入立即触发新一轮子抽样清洗，始终离群的点被永久剔除。
5. **不重复抽样**：初始池的配对空间固定且有限（~5000 对），每对至多评估一次，保证最坏情况时间上界。
6. **约束收紧反馈**：模型越准 → 约束越严格 → 非法抽样跳过率越高 → 有效迭代效率越高。
7. **纯度优于数量**：宁可少而精（30~50 颗亮星初始池），不可多而噪。SCM 的 Configuration 维度正是基于"亮星局部构型是独特的"这一假设。
