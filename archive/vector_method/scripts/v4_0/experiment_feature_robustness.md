# V4.0 特征区分度鲁棒性实验

## 实验目标
验证 density_corr + coverage_iou 能否在所有帧、所有翻转模式下鲁棒区分正确/错误匹配。

## 实验设计

### 星点选取
- 饱和星≥50: 使用全部饱和星
- 饱和星<50: 全部饱和星 + flux最高的非饱和星补足50颗
- 匹配集U = 选取的星点(中心化到弧秒坐标)

### 星表侧选取
- 搜索直径 = FOV对角线(弧秒)
- 计算图像侧星点密度 = |U| / FOV面积
- 星表侧取星数 = density × 搜索面积(圆形) × 1.5安全系数
- 取最亮的N颗Gaia星

### 变换与评分
- 4种翻转模式(mode=0,1,2,3)平行计算
- 每模式: 随机1点抽样(50×M次) → θ直方图聚类 → density_corr + coverage_iou
- 变换后裁剪Wt到FOV内再算特征(解决M>>N噪声问题)
- 评分 = peak_count × good_dc_med

### 质量标签(仅用于验证, 不参与评分)
- θ直方图峰值5°内 + s在峰值3%内 = 好
- θ距峰值>30° = 坏

### 关键指标
- **dc_sep** = density_corr分离比 = 好变换dc中位数 / 坏变换dc中位数
- **ci_sep** = coverage_iou分离比 = 好变换ci中位数 / 坏变换ci中位数
- dc_sep >> 1 表示density_corr能有效区分好/坏变换

## 前期发现 (2026-06-10/11)

### 单帧交叉验证 (M20_T2 Red, mode=1)
- density_corr: Cohen_d=11.34, 成本1, F1=0.922 → 性价比最高
- coverage_iou: Cohen_d=6.61, 成本1, F1=0.926
- 好变换10"内匹配47/50星, RMS=3.61"(3.73px) → 变换正确
- 最优低成本组合: density_corr + coverage_iou + angle_corr (成本3)

### 全帧测试 (26帧, 仅mode=1)
- nsat≥20宽带帧: 分离度1.7-2.2x, 特征有效
- nsat<10窄带帧: 分离度0.9-1.4x, 特征失效
- M20 Blue(mode=1): 分离度仅1.1x, mode可能不对

### 4模式测试 (29组合×3帧=87帧, 抽样300次)
- density_corr在mode=0时失效(Y方向翻转不匹配)
- coverage_iou对模式更鲁棒但区分度偏弱
- 抽样不足导致θ峰值不稳定

## 最终实验结果 (2026-06-11, 4模式×大量抽样)

### 关键改进
1. 抽样数 = 50×M (保证正确配对命中率≥50次)
2. 变换后裁剪Wt到FOV内再算特征
3. 饱和星<50时补足50颗

### 核心结论

1. **density_corr在nsat≥5的所有帧上鲁棒区分正确/错误模式**
   - 正确模式: dc=0.6-0.8
   - 错误模式: dc=-0.1~0.15
   - 阈值dc=0.3即可完美分离(除nsat=0帧)
   - dc_sep通常20-160x

2. **coverage_iou区分度弱于density_corr**
   - 好/坏ci都在0.3-0.7范围
   - 对翻转模式不敏感, 无法有效区分

3. **nsat=0的帧(NGC6302)特征失效**
   - 无饱和星, 补足50颗flux高的非饱和星
   - 质心精度差, dc最高仅0.16-0.53
   - 需要其他策略(如2点抽样)

4. **mode=1和mode=2经常dc相同**
   - flipY(mode=1)和flipX+flipXY(mode=2)在θ差90°时等价
   - 两者都可能是正确模式, 需要后续验证

5. **抽样数是关键**
   - 300次抽样: θ峰值不稳定, 好变换标签不准
   - 50×M次抽样: θ峰值清晰, dc_sep从1-2x提升到20-160x
   - 抽样成本极低(~0.1ms/次), 可大量抽样
